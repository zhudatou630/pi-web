# 会话切换与分屏

没有会话标签条：侧栏（手机上是抽屉）就是会话切换器。决策和理由见 `docs/adr/0005-sidebar-as-session-switcher.md`。

## 两格和挂载缓存

对话区最多两格：左格（primary）常在，右格（secondary）只在分屏时出现。每格显示一个会话，或者一个草稿的新建会话页。一格有焦点；侧栏点击、快捷键、通知点击和 `?session=` 都作用在有焦点的那格。同一个会话（或同一目录的草稿）不会同时出现在两格里：选中另一格正在显示的会话，只把焦点移过去。

秒切靠挂载缓存：切走的会话保持挂载、只是隐藏（`display: none`，滚动位置不丢）。保留的有两格正在显示的、最近 5 个隐藏的会话（`HIDDEN_CACHE_SIZE`），以及缓存里所有运行中的会话（运行、子 agent 在跑、等待输入）：运行中的不淘汰，页面里的完成和等待通知才不会丢；结束后在下一次切换时按最近使用顺序淘汰。被淘汰的会话再回来时重新加载，滚动位置从按会话记录的位置恢复。服务端续期（每 30 s，`useOpenSessionLeases`）只覆盖缓存里的会话：淘汰就相当于以前关掉标签，runtime 空闲 10 分钟后释放。

| 操作 | 行为 |
| --- | --- |
| 侧栏单击 | 在焦点格显示；原来那个会话留在缓存里 |
| 双击 | 等同单击 |
| 行菜单「在右侧分屏打开」、中键、把行拖到对话区右半边 | 在右格显示并获得焦点（窗口能分屏时才有；左格正在显示的会话该项禁用） |
| 每格标题栏的 × | 结束分屏；另一格成为左格、获得焦点，不重新挂载 |
| 窗口变窄放不下两格 | 合并，保留有焦点的那格 |
| 新建会话（侧栏顶部、项目行「+」） | 在焦点格显示该目录的新建会话页；每个目录一份草稿，离开时存到该目录名下（`parked-new:<cwd>`），下次在这个目录新建会话就回来；导航从不丢弃草稿 |
| 草稿发送成为会话 | 原格原位，组件不重建 |
| Fork（行菜单、`⋯`、消息 Fork） | 新会话在源会话所在的格里替换源会话，源会话留在缓存；如果 Fork 完成前焦点已经离开，只出现在侧栏 |
| 旁问 | 在另一格打开（需要时分屏）；不能分屏时在原格替换，顶栏「返回主会话」回去 |
| Agents 面板 | 点行原位切换；中键在右侧分屏打开 |
| 删除正在显示的会话 | 分屏时关掉那一格；单格时显示侧栏当前目录的新建会话页 |

分屏时侧栏两格对应的行都是选中底色。每格的标题栏：标题、「项目 · 分支 ⌄」、改动 N、条件工具、`⋯`、×（仅分屏时）；面板开关全局只有一个，在最右端。没有焦点的那格标题降一档灰（`--text-muted`），工具不可点，点它只是把焦点移过去。费用和上下文占用在各自输入框下方。

实现：`lib/chat-view-state.ts` 是纯状态（两格、缓存淘汰、键盘导航、刷新恢复），`components/AppShell.tsx` 持有 `chatView`。所有挂载的聊天组件在同一份带稳定 key 的列表下，按挂载顺序排列（从不重排，移动节点会丢滚动位置），由 CSS Grid 决定位置。

## 键盘

| 键（macOS 用 Option） | 作用 |
| --- | --- |
| Alt+↓ / Alt+↑ | 侧栏显示顺序里的下一个 / 上一个会话（不循环；搜索时是搜索结果） |
| Alt+Shift+↓ / Alt+Shift+↑ | 下一个 / 上一个需要你处理的会话（NEEDS YOU 顺序，按全部会话计算，循环） |
| Alt+K | 会话切换器：打开侧栏搜索并聚焦；Enter 打开第一个结果，↓/↑ 在结果间移动 |

都跳过另一格正在显示的会话，在焦点格打开。同时按 Ctrl 或 Cmd（AltGr）、输入法组字、焦点在终端里、有对话框打开时不响应。冲突检查见 ADR 0005。

## 刷新与返回

两格各显示什么、焦点格和分屏比例保存在当前浏览器标签页的 `sessionStorage`（`pi-chat-view`），只存会话 id 和草稿 key，不存聊天内容或目录缓存，挂载缓存不恢复。目录列表成功返回后再恢复，已删除的会话丢弃（只剩右格时它移到左边）。手机或窄窗口按合并规则处理。

URL 的有效 `?session=` 优先：它已经在某格就聚焦那格，否则替换有焦点的那格。不存在的 id 回退到保存的状态；显式 `?cwd=` 仍新建草稿，不恢复旧布局。旧版的 `pi-chat-workspace` 直接删除；旧版的 `pi-chat-draft-tabs` 里仍有内容的草稿，每个目录第一份存到该目录名下，然后删除这个键。布局存储不可用时只放弃恢复，不影响聊天。

草稿按浏览器标签页保存正文、引用和图片。历史编辑的目标只在内存里，因此编辑期间也只在内存保留草稿，避免刷新后误发到当前分支；取消编辑后恢复持久化。运行中的内置命令不会通过刷新回到输入框。确认删除会话时清理对应草稿，退出登录时清理本标签页的所有草稿。

未命名旁问在标题栏和 Agents 中统一按同一 family 的创建顺序编号（`Side chat 1/2`，中文“旁问 1/2”）；已有问句名称不改。

## 项目文件夹丢失

会话仍可阅读，发送被拒绝时保留输入。普通会话可用输入框上方的「分叉到其他文件夹…」选择新目录：复制全部历史（包括其他分支），保留源会话，草稿随新会话打开。已恢复原目录的会话、旁问和子代理不支持此操作。目录选择和新建会话一样可以登记新的文件访问根；服务端只登记校验后的实际目录。

## 扩展主动结束会话

扩展 `ctx.shutdown()` 等待工作结束后只关闭对应 runtime。当前会话保留为只读，显示持续的结束通知；它不再自动重连，草稿、滚动位置、所在格与另一格都不变。关闭后重新打开该会话（或显式刷新页面）可正常启动新的 runtime；会话文件若被扩展删除则不会在旧路径重新创建。详见 `docs/extensions.md`。

## 文件面板标签

右侧文件与终端标签共用一个标签条，只有一组，没有分屏和移组。标签条开头固定「改动」「文件」两个视图，不能拖动或关闭（见 `docs/ui.md` File panel）；下表只说内容标签。

| 操作 | 行为 |
| --- | --- |
| 拖动标签 | 文件和终端可任意混排；顺序存于 sessionStorage `pi-web:panel-tab-order`，未出现在顺序里的新标签追加到末尾 |
| 原位替换（预览文件被替换、终端重启） | 新标签继承旧标签的位置 |
| 标签右键菜单 | 固定预览、复制路径、复制相对路径（文件在 cwd 内时）、在文件树中定位（同上）、关闭、关闭其他、关闭右侧；终端只有关闭类 |
| 在文件树中定位 | 右栏切到「文件」视图和该标签的 cwd，展开祖先目录、滚动到该文件并短暂标记 2 秒 |
| Delete 键 | 关闭当前聚焦的标签 |

移动端不提供右键菜单和拖动。实现：`components/TabBar.tsx`，顺序函数在 `components/file-tab-state.ts`。
